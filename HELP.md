Start a comment with one of these:

- `@kodi-review` alone: review this pull request, or what changed since the last review.
  Needs write access. [More](https://github.com/MikeSiLVO/kodi-review#how-a-review-runs)
- `@kodi-review format`: check the changed lines against clang-format. Anyone can ask, once per
  commit. [More](https://github.com/MikeSiLVO/kodi-review#formatting-only)
- `@kodi-review skin`: check the skin this pull request changes, or Estuary, with kdk. Anyone can
  ask; a commit already checked is checked again only after my checks are updated.
  [More](https://github.com/MikeSiLVO/kodi-review#skin-check)
- `@kodi-review` and a question: an answer from the code. Needs write access.
  [More](https://github.com/MikeSiLVO/kodi-review#asking-questions)
- `@kodi-review help`: this list. Anyone can ask.
