- convention: External stream names are `<video>.<tokens>.<ext>`, tokens split on space, dot and hyphen and read from the end: the first language token wins (`.en.fr.srt` is fr), `_` stands for the BCP 47 hyphen (`pt_BR`), alpha-3 becomes alpha-2 where one exists, only none, default, forced, original and impaired are flags (sdh, hi, cc join the name), and leftover tokens name the stream. | check: name parsing changes test alpha-3, a `_` region, a flag before the language, two languages, and no word read as both flag and language | at: `xbmc/Util.cpp:CUtil::GetExternalStreamDetailsFromFilename`
- scenario: A subtitle belongs to a video when its name without extension starts with the video's name, case-insensitive, encoded or decoded, so every subtitle of `Movie 2.mkv` also matches `Movie.mkv`. | check: associated-file matching (subtitles, external audio) handles one video name being a prefix of another | at: `xbmc/Util.cpp:CUtil::ScanPathsForAssociatedItems`
- convention: External subtitles are searched beside the item's dyn path, so .strm and plugin items search beside the resolved URL; the scan skips DVD and PVR input, UPnP, non-LAN internet streams, playlists and items with no-ext-subs-scan, and items can list files in subtitle:1..N properties. | check: new playback paths or GetDynPath changes keep the search location and the skip list | at: `xbmc/cores/VideoPlayer/VideoPlayer.cpp:CVideoPlayer::OpenInputStream`
- convention: CLanguageTag reads `en`, `eng`, `EN`, `English`, ISO 639-2/B and /T (`ger`, `deu`) and withdrawn codes (`iw` as `he`) as one language. Equality compares whole tags apart from case (`en-AU` is not `en`); Matches compares languages (`en-AU` matches `en-GB` and `eng`, `zh-yue` matches `zh` not `yue`); `und` equals absent, `zxx` does not, free text matches only itself. | check: language comparisons use Matches where the language is what counts; tests cover B against T, a withdrawn code, a region against a bare language, `und` and free text | at: `xbmc/language/LanguageTag.cpp:CLanguageTag::Matches`
- convention: Track names carry a language in braces anywhere (`name {en}`, `{es-419} name`, `{ EN }`); the first valid brace wins and `{}` gives none. | check: code reading or rewriting stream names keeps a `{lang}` and takes no language from stray braces | at: `xbmc/language/LanguageTag.cpp:CLanguageTag::FindInText`
- convention: While subtitles show, next past the last stream and previous from the first hide them, and cycle wraps to 0 still showing; while hidden, next and previous show the current stream (previous from 0 shows the last) and cycle does nothing; zero streams or an index at or past the count are no-ops. | check: track action changes test zero streams, one stream, hidden subtitles and an index at the count | at: `xbmc/video/PlayerControllerActions.cpp:CPlayerControllerActions::ExecSubtitleTrackAction`
- trap: Hiding a bitmap subtitle whose language differs from the audio closes its stream (image subtitles stay open only to read the forced flag) while it stays selected, and the reported indices are rebuilt from open streams on every OpenStream. | check: index derivation keeps a selected but closed subtitle, and that memory resets per playback | at: `xbmc/cores/VideoPlayer/VideoPlayer.cpp:CVideoPlayer::UpdateContentState`
- scenario: A libass style change made while nothing is on screen must place the next line, and a style is applied once, with only a new style object counting as a change. | check: style changes take effect on the next line without reapplying every frame | at: `xbmc/cores/VideoPlayer/DVDSubtitles/DVDSubtitlesLibass.cpp:CDVDSubtitlesLibass::ApplyStyle`
