Start a comment with one of these:

- `@kodi-review` alone: review this pull request's code, or what changed since the last review. Needs write access. [More](https://github.com/MikeSiLVO/kodi-review#add-on-review)
- `@kodi-review addon`: check the add-on this pull request adds or updates. Anyone can ask. [More](https://github.com/MikeSiLVO/kodi-review#add-on-check)
- `@kodi-review help`: this list. Anyone can ask.

An add-on already checked at the same commit is checked again only after my checks are updated or the target branch changes. Each pull request gets my check when it opens and after each push or target branch change.
While review findings are open, each push gets a re-review.
